## MusicTag Manager 1.0.3

### 새 기능
- **곡 파일 삭제**: 곡 목록에서 우클릭 → "파일 삭제…". 파일 위치·재생 시간·용량·비트레이트를 확인하고 미리 들어 본 뒤 삭제할 수 있어요. 파일은 휴지통으로 이동하고, Music 앱의 모든 플레이리스트에서도 함께 빠져요.
- **작업 중지**: 식별·적용 중에 "중지" 버튼으로 멈출 수 있어요. 끝난 곡까지는 저장되고, 적용은 작업 이력에서 이어서 실행할 수 있어요.

### 안정성
- 텍스트는 바뀌었는데 커버만 실패한 곡도 작업 이력에서 되돌릴 수 있어요.
- 식별·적용 중에는 플레이리스트 변경·되돌리기 등 다른 작업을 막아 기록이 꼬이지 않게 했어요.
- 네트워크가 끊기면 커버만 빠진 채 적용되지 않고 작업을 멈춰요.
- 손상된 음원 파일에서 오디오 지문 생성이 멈추던 문제를 고쳤어요.
- 일시적인 네트워크 오류로 멀쩡한 커버가 '쓸 수 없음'으로 남던 문제를 고쳤어요.
- "곡 3,000개 초과 보관함에 쓰지 않기" 안전장치를 기본 꺼짐으로 바꿨어요 (설정 > 일반에서 켤 수 있어요).

### 화면
- 상단 탭을 하나의 캡슐 메뉴로 바꾸고, 정보 영역을 줄여 곡 목록을 더 넓게 보여 줘요.
- 작은 화면·최소 창 크기에서도 직접 수정 창이 잘리지 않아요.
- 영어 화면에서 오류 메시지와 권한 요청 문구도 영어로 보여요.

### 검수표(CSV)
- 엑셀에서 열었다 저장해도 곡 ID가 깨지지 않아요.
- 엑셀이 저장한 한국어(CP949)·유니코드 CSV도 가져올 수 있어요.

> 요구 사항: macOS 14 이상, Apple Silicon Mac
